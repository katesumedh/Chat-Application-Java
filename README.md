### How To Run

#### 1. Open Terminal

##### In the first terminal, compile and run the server:

```bash
javac Server.java
java Server
```

#### 2. Open another terminal

##### In the second terminal, compile and run the server:

```bash
javac Client.java
java Client.java
```
